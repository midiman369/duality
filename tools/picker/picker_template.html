Connecting…

Priority order is the order boxes are handed out: a family higher on the list takes an insert box from a lower one. Duality picks one type per box from the ticked list using the song's seed; a favoured type counts twice and a less-often type counts half. Hex pairs are the MSB/LSB written to 40 03 00.
